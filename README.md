## Compilación y ejecución

Para compilar, ubicarse en el directorio raíz de la práctica y ejecutar el siguiente comando:

```
sudo docker build -t simulador .
```

Y para ejecutar las pruebas, ubicarse en el directorio raíz de la práctica y ejecutar el siguiente comando:

```
sudo docker run -it simulador
```
